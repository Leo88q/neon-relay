# Third-party notices

Neon Relay is a derivative work. This document records every third-party work that is
present in the tree, its license, its attribution status, and — where the license cannot yet
be satisfied for a commercial release — the release gate that keeps it out of shipped builds.

The machine-readable companion is [`ASSET_MANIFEST.csv`](ASSET_MANIFEST.csv)
(`path,sha256,type,author,copyright,license,source_url,attribution,action`), regenerated with

```bash
./scripts/check_assets.sh --regenerate          # rewrite the manifest
./scripts/check_assets.sh --licenses            # coverage + hashes + license texts
./scripts/check_assets.sh --release --licenses  # release gate (must pass before shipping)
```

Verbatim license texts live in [`../licenses/`](../licenses/).

## 5. Skins (`data/skins/`, `data/skins7/`)

All shipped skins are **original Neon Relay artwork** generated by
`scripts/build_neon_skins.py` and `scripts/build_neon_skins_all.py`
(BL-15, with the BL-15 3/3 sweep completing the rewrite): every
upstream-named 0.6 sheet (111 names) and every 0.7 component mask
(17 bodies, 5 eye sets, hands/feet mitts, 50 markings, 7 decorations,
bot chassis, xmas_hat, plus 49 descriptors) was redrawn procedurally
in place over the same filenames. The geometry is not a recolour:
each name picks one of 17 unique silhouette families (round, cat,
fox, bear, koala, monkey, mouse, dog, piglet, raccoon, beaver,
bat, dragon horns, spikes, crown, sci-fi antenna, ninja hood,
sunburst) combined with a per-name hue/sat shift on the Night
Drive palette (`docs/DESIGN_SYNTHWAVE.md`) and a unique chest accent
(stripe / grid / band / circuit / glitch). Eye sprites use five
distinct layouts (colorable, negative, standard, standardreal, x_ninja).
The 50 marking masks cover a hand-drawn composition each (stripes,
cammo, lightning, hearts, stars, drops, scars, wings, yin-yang,
thunder, blush, panda, setisu, wildpatch, ...). No upstream skin
pixel remains in the release tree.

Historical record (files as vendored before BL-15, now replaced):
16 Teeworlds-era skins (Magnus Auvinen, zlib), `wartee` (Obst, zlib),
28 Whis skins (CC-BY), `coala_*`/`santa_*` (DanilBest / forsaken, CC-BY-SA 3.0),
`kitty_*`/`bomb` (Ravie, CC0), `kitty_x_ninja` (patwo.*, CC0),
`demonlimekitty`/`nanas`/`nersif` (Miper, CC-BY-SA 3.0) and unnamed rest
(CC-BY-SA 3.0 default rule); `data/skins7/**` carried no per-file license.

## 7. Unattributed CC-BY-SA 3.0 content (attribution gap → block-release)

48 assets remain gated, down from 250 at the start of the original-art pass:

* `data/shader/*` (32 files): upstream applies the CC-BY-SA 3.0 default rule
  but names no author, so the attribution required by §4(b) cannot be produced
  from the tree. Replacement with original shaders is deferred.
* `data/maps/ctf*.map`, `data/maps/dm*.map`, `data/maps/coverage.map`
  (14 files): classic upstream gameplay maps and the `gameworld_test` fixture;
  no author is named anywhere in the tree (empty map-info blocks, no
  `data/maps/license.txt` stanza, not generator outputs). Kept because the
  game needs a map pool and the C++ test suite needs `coverage`; re-authorship
  or an upstream author lookup is future work.
* `assets-src/maps/warm-workshops/*` (2 files): art-direction prototype, not
  packaged as playable map assets; approval and integration pending.

Everything else the pass touched is resolved. The 131 upstream `.wv` audio
mirrors were deleted — the `.wav` masters are originals
(`scripts/build_neon_sounds.py`, BL-18; `datasrc/seven/content.py` now references
`.wav`, and all 29 `FileList` patterns resolve on disk). 27 unused upstream
`data/mapres/*.png` sheets and `data/assets/game/game_06.png` were deleted; the
remaining 27 `data/mapres/*.png` filenames were repainted pixel-original
(`scripts/build_neon_backgrounds.py`, `scripts/build_neon_tilesets.py`,
`snow.png` included, so the Sound maps' external reference is clean).
`data/debug_font.png`, `data/gui_buttons.png` and the
`data/themes/{auto,none,rand}.png` icons were redrawn
(`scripts/build_neon_font_buttons.py`); `data/wordlist.txt`,
`data/fonts/index.json`, `data/touch_controls.json`, `data/autoexec_server.cfg`,
`data/maps7/readme.txt` and `other/emscripten/{index.html,server.py}` were
regenerated or reserialized from scratch. `data/announcement.txt` and
`data/censorlist.txt` ship empty (zero-byte placeholders, nothing to attribute).
The 9 `data/themes/*.map` theme maps and 5 theme previews were deleted together
with their `CMakeLists.txt` entries (the `auto`/`none`/`rand` icons and the
`nightdrive` theme remain; `themes/auto.png` was missing from the packaging
list and is now included). The retired night-drive recolor script
(`scripts/build_neon_mapres.py`) refuses to run so it cannot remap the
originals in place.

Options recorded for the rights review:

1. obtain the author list from upstream contributors, or
2. replace the assets with original artwork, or
3. ship with a good-faith attribution page naming the upstream project plus the full license text.

Until one is chosen, `scripts/check_assets.sh --release` fails on the remaining
block-release set (shader, warm-workshops prototype, unattributed maps), so no
commercial build can include them. This is the largest remaining release blocker
(see `KNOWN_LIMITATIONS.md`, BL-05).

## 10. Release gate

A release build is produced only when all of the following pass in CI:

```bash
./scripts/check_assets.sh --release --licenses   # no block-release asset, all texts present
./scripts/check_branding.sh --release --check-translations
```

plus the manual sign-off items in `RELEASE_CHECKLIST.md` (rights review of §7, trademark
clearance of the Neon Relay mark, and bundling of the verbatim CC/OFL legal codes listed in
`licenses/README.md`).
