# Проба готовых карт — отдельно от Neon Relay

Это исследование исходных трасс, **не утверждённый новый стиль игры**. LearnToPlay
Sound и Heights не заменяются. Чужие `.map` и превью не включаются в Git/CMake/поставку.

## Кандидаты

| Карта | Автор из каталога | Категория / звёзды | Размер в тайлах | Почему пробуем |
|---|---|---|---|---|
| **Late Evening** | Bixes | Solo / 2 | 350×150 | Первый кандидат: одиночная трасса, острова, перепады высот |
| Tangerine | Oblique | Novice / 1 | 500×180 | Воздушные острова, но есть зона отрицательной гравитации |
| Planet Mars | Aoe | Novice / 4 | 435×952 | Выраженная вертикальность; не первый вариант для простого старта |
| The Forest | YoDa & Nixus | Novice / 3 | 430×162 | Несколько уровней; нет внешних зависимостей изображений |

Звёзды относятся к своей категории, это не единая шкала между Solo и Novice.
Категория Novice сама по себе не гарантирует прохождения одним игроком.
Оценки композиции сделаны по обзорным рендерам, не по ручному прохождению.

## Что реально проверено

Четыре файла скачаны из официального репозитория с закреплённой ревизией,
прочитаны нашим v4-парсером. SHA-256, размеры, слои, envelopes, внешние изображения
и встроенные настройки записаны в `catalog.json`. Все необходимые внешние
изображения найдены в текущем `data/mapres`; внешних звуков нет.

Встроенные настройки **не переписываются**:
- Tangerine: `tune_zone 1 gravity -1`;
- Late Evening: `sv_solo_server 1`;
- остальные два файла не содержат встроенных команд настроек.

Файлы не пересохранены генератором. Проверка хэша выполняется до установки и
повторно при использовании кэша. Повреждённый/изменённый кэш не перезаписывается
молча. Полное прохождение и нативный визуальный просмотр этих четырёх карт
агентом пока не выполнены.

## Лицензии: пока не включать в релиз

Во всех четырёх файлах поля author/credits/license пусты; авторы взяты из
официальных `types/*/maps.txt`. GitHub License API для репозитория не нашёл корневую
лицензию. Это **не означает ни общественное достояние, ни запрет игры**: README
официального проекта прямо описывает запуск карт на собственном сервере.
Но возможность изменять/распространять каждую карту и её встроенную графику
в составе коммерческого продукта ещё нужно подтвердить отдельно. Статус всех
кандидатов — `unverified-do-not-ship`.

## Запуск Late Evening на Mac

Обновить ветку. Дополнительные Python-пакеты для команды запуска не нужны:

```sh
cd "$HOME/neon-relay-mac-preview"
git pull --ff-only origin arena/01a0b21c-neon-relay
python3 scripts/try_reference_maps.py list
```

Терминал 1 — **отдельный сервер на порту 8304**:

```sh
cd "$HOME/neon-relay-mac-preview"
python3 scripts/try_reference_maps.py server "Late Evening"
```

Команда скачивает только закреплённый исходный файл, проверяет его и запускает
**уже собранный локальный** `build-mac/neonrelay-server`. Сеть нужна для первого
скачивания. При блокировке raw.githubusercontent.com можно использовать
установленный и подключённый `gh` как резервный транспорт.
Если бинарника нет: `cmake --build build-mac --target game-server -j 4`.
Иной путь задаётся через `--server-bin /путь/к/neonrelay-server`.

Терминал 2 — существующий клиент:

```sh
cd "$HOME/neon-relay-mac-preview"
./build-mac/neonrelay "gfx_fullscreen 0" "gfx_screen_width 1200" "gfx_screen_height 760" "cl_show_welcome 0" "connect 127.0.0.1:8304"
```

Ctrl+C останавливает пробный сервер. Для следующего кандидата смените имя в
команде запуска и переподключите клиент. Обычный сервер на 8303 не затрагивается.
Кэш, storage.cfg и серверная конфигурация пробы находятся в
`.cache/reference-maps/<имя>/`. Обычный пользовательский autoexec не подключается;
переменные `NEONRELAY_*` не передаются дочернему серверу. Это локальная проверка
маршрута, не турнир и не интеграция экономики.

  трассу с сильным отдалением и не равны картинке в игровом масштабе.

Следующий этап после пробы: выбрать трассу, завершить проверку прав и подготовить
один участок Sound/neon на её настоящей геометрии. Material Maker/Effekseer пока
не установлены и не интегрированы; текущая проба проверяет основу карты, не эти инструменты.
