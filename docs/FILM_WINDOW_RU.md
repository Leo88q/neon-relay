# Оконный язык «Кадр плёнки»

Статус: **вертикальный срез выполнен** (попопы меню, платы коннекта/загрузки,
движковые попопы, зеркало на сайте + гейт паритета). Раскатка на остальные
поверхности — по списку в конце.

## Почему не стекло со скруглением

Скруглённая стеклянная панель с неоновой обводкой — профиль, который выглядит
как сгенерированный, кем бы ни был нарисован. Окно обязано быть вещью из мира
игры (диегетика), а не абстрактным контролом. Выбранная вещь: **кадр
проявленной плёнки**. Связь с игрой прямая: демки и записи матчей — архив
плёнки; каждое окно — кадр из этого архива.

## Анатомия кадра

Рисунок один и в клиенте, и на сайте; числа живут в токенах парой.

| Элемент | Клиент (`neon_style.h`) | Сайт (`--film-*`, стенд) | Что это |
| --- | --- | --- | --- |
| Полоса перфорации | `FILM_SPROCKET_W` | `--film-sprocket` | тёмные полосы по краям плёнки |
| Отверстие перфорации | `FILM_HOLE_W` / `FILM_HOLE_H` | `--film-hole-w` / `--film-hole-h` | прямоугольные проколы в полосе |
| Шаг кадра | `FILM_HOLE_STEP` | `--film-hole-step` | расстояние между проколами |
| Кадровая полоса | `FILM_HEADER_H` | `--film-header` | заголовок с счётчиком кадра |
| Регистрационная метка ⊕ | `FILM_MARK_R` | `--film-mark-r` | окружность + перекрестие по углам рамы |
| Краевой код | `FILM_EDGE_CODE` | `--film-edge` | короткие штрихи у верхней кромки |
| Протяжка | `FILM_ADVANCE_SECONDS` | (своя тайминг-кривая) | длительность анимации появления |

Правила:

1. **Счётчик кадра `FRM 0042`** в клиенте рисуется кодовой пиксель-гарнитурой
   3×5 (квады, без шрифтового движка) — хром не зависит от рендерера текста и
   от разрешения. Номер кадра стабилен по типу попапа (`100 + POPUP_*`), чтобы
   одно и то же окно всегда имело один номер.
2. **Цвет проявки** — акцент кадра: штатные окна — циан (`CYAN`), аварийные
   (разрыв связи, неверный пароль, предупреждение) — розовый (`PINK`). Других
   акцентов у окон нет.
3. **Протяжка** — дискретная «механическая» подача в три подшага, каждый со
   своим сглаживанием; во время протяжки перфорация прокручивается вместе с
   плёнкой. Никакого «плавного всплытия» и дребезга прозрачности.
4. **Компактные плиты** движковых попопов (палитра, выбор) — киноячейка:
   перфорация только слева (мелким плитам тесно), контур и краевой код.

## Где исполняется

* `src/game/client/neon_window.h/.cpp` — `DrawFilmFrame` (полный кадр) и
  `DrawFilmPlate` (киноячейка); только примитивы графики, без текстур.
* `src/game/client/components/menus.cpp` — попопы меню и системные платы
  (загрузка, коннект, лоадинг).
* `src/game/client/ui_popups.cpp` — движковые попопы (сообщение, подтверждение,
  выбор, палитра цвета).
* `design/potato-arena/index.html` — CSS-компонент `.filmwin` и витрина
  «Кадры плёнки».

## Паритет и гейты

`scripts/test_film_window.py` (в картофельном шаге `ci.yml` и в
`scripts/ci-local.sh`) проверяет: каждый `FILM_*` токен имеет зеркало
`--film-*` с тем же числом; клиент рисует через `NeonWindow::*`; старые
скруглённые плиты не вернулись; витрина и спецификация на месте. Правка
геометрии с одной стороны без другой роняет гейт — это и есть предохранитель.

## Раскатка (следующие шаги)

1. Кнопки внутри окон — «штампы» (как на витрине стенда) вместо текущих
   `DoButton_Menu`; отдельно штамп подтверждения/отказа для `POPUP_CONFIRM`.
2. Вкладки страниц меню как папки архива с ярлычками (единая хром-рейка
   страниц вместо текущей таббар-полосы).
3. Лендинг: `.filmwin` для карточек-примеров окон (сейчас компонент только на
   стенде; хэши лендинга пинованы `INTEGRITY.json`, правка — вместе с
   `check_landing_integrity.py --write`).
4. Тосты/алерты как «обрывки плёнки» — отдельный маленький хром.
