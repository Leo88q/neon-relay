# Персонажи Neon Relay — тексты витрины

Это встроенный каталог и локальная тестовая примерка, а не опубликованная
коллекция NFT на внешнем маркетплейсе. Покупки и выпуск NFT пока отключены.
Цены — параметры каталога. «Навыки» ниже описывают характер и легенду: они
не меняют скорость, прыжок, крюк, урон, физику или шансы на победу.

Все игровые спрайт-листы — 256×128 RGBA с отдельными кистями и ступнями.
Лица теперь нарисованы внутри сгенерированного тела: сменных глаз и эмоций нет.
Канонические прозрачные иллюстрации 1024×1024 находятся в
`assets-src/potato/generated_bodies/`, крупные портреты витрины — `data/portraits/`.
Это сгенерированные иллюстрации с объёмным светотеневым рисунком, не 3D-модели.
Проверенные отдельные конечности сохранены. Женские лица адаптированы по
референсам; исходный `face_alt/` не изменён. Это не пиксельно идентичные копии.

Главный экран и витрина используют непрозрачные тёмные панели. В узкой
компоновке витрина показывает по четыре карточки (две колонки), листание и
отдельный экран выбранного персонажа. Кнопки примерки/навигации увеличены.
Остальные служебные экраны не считаются полностью переработанными.

## Проверка на Mac

После обновления исходников пересобрать `game-client`. Сервер для этой
правки пересобирать не нужно. В главном меню открыть «Персонажи», выбрать
карточку и нажать «Примерить бесплатно (тест)». Проверить заморозку на карте,
сохранение выбранного тела, ходьбу, прыжок, крюк и эмоции.

В ресурсах клиента остались только десять игровых скинов. Удалены 235 старых
PNG/JSON файлов из `data/skins` и `data/skins7`; лицензии сохранены. Загрузка
по произвольному имени, старому префиксу или сетевому адресу больше не является
путём получения внешности: не-каталожные имена нормализуются в Нокса.
Это действует и для старых записей повторов. Старый визуальный рендерер 0.7
удалён; совместимость формата сообщений сохранена, но отдельный каталог
частей 0.7 не поддерживается. Такие аватары показываются через новый fallback.

Колесо эмоций удалено из компонентов клиента и touch-кнопок, старый bind
`+emote` очищается при чтении. Смайлики/индикаторы чата и AFK над персонажем
не рисуются. Сетевые поля эмоций оставлены для совместимости протокола, но
не меняют лицо. Физика, заморозка, чат и управление не удалены.

Для проверки нужен новый исполняемый файл, а не только обновлённые картинки.
Удаление старых файлов из текущей версии не переписывает историю Git и не
удаляет вручную созданные файлы из пользовательского каталога. Обновлённый
загрузчик их не выбирает как старые скины. Старый исполняемый файл, запущенный
из другой папки, естественно, не получает эти исправления.
