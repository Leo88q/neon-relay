# Большая хромированная DM-арена — v4 темный пиксельный неон

Отчёт четвёртого этапа. Боевые правила: **[NEON_DM_RU.md](NEON_DM_RU.md)**.

## Что нового в v4 — темная фактура

Пользователь попросил заменить фактуру на пиксельный неоновый темный.

**Платформы теперь темные:**

- `chrome_dm_materials.py` генерирует `chrome.png` 1024×1024 как 8×8 тайлов 64×64:
  - база темная 12-22 (ночной неон), шум 8px блоками (18,28,52)
  - пиксельные искры циан (77,227,247) и маджента (255,46,136)
  - верхний циановый неон 3px + свечение для yy==0, боковые темные кромки
  - нижняя тень для глубины
- `bevels.png` — темные кромки (6,10,22) с циановой подсветкой сверху

**Фон тоже темный:**

- Фото атриума затемнено на 62% (смешивание с (8,10,22)), синий тинт
- Вуаль теперь темно-индиго (0.12,0.18,0.32) + циановые риббоны
- Виньетка 32%, bloom 22%, пиксельный дитер 800 точек

Результат — темный пиксельный неон, читаемый в движении, без светлого муара.

**Размер и функционал сохранены из v3:** 520×180, 43 спавна, все 6 оружий, freeze в front-слое.

## Геометрия v3/v4

- Оригинал dm7 146×120 в (0,0) кроме 3 стыков
- Atrium 280-470, Spire 430-475, Lower field 155-440 с death-ямами
