NEON RELAY WEB

This page runs an experimental browser build of the Neon Relay client. Most public servers stay unreachable from here: a server must be built with WebSocket support to accept browser clients.

Drop a .demo replay, a .map file or a neonrelay:// link here (or click to pick a file) to open it on launch. Drops also work on the game window itself once running.
