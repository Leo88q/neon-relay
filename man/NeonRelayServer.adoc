== NAME
neonrelay-server - Starts the Neon Relay game server.

== SYNOPSIS
*neonrelay-server* [_OPTION_]... [-f _CONFIG_FILE_]...

== DESCRIPTION
The Neon Relay game server is authoritative for gameplay and for every signal the reward
service accepts. It is a standalone derivative of the upstream DDNet server; see
`UPSTREAM_BASE.md` and `license.txt` in the repository for the exact upstream commit and
for attribution.

By default the server does *not* register with any master server (`sv_register 0`, empty
`sv_register_url`) and does not contact third-party services. Point `sv_register_url` at
your own master server deployment to list a server publicly.

== EXAMPLES
*neonrelay-server* -f myfile.cfg

*neonrelay-server* -f myfile.cfg -f myfile2.cfg

*neonrelay-server* \'sv_register 0' \'sv_name "Neon Relay server"'

== Options

=== Configuration file
*-f* _CONFIGURATION_FILE_::
Load _CONFIGURATION_FILE_ instead of the default _autoexec_server.cfg_

=== Other options
All options are documented in `data/autoexec_server.cfg` and in
`src/engine/shared/config_variables.h`.

== REWARDS
Server-side reward events are produced by the optional `src/neonrelay` module. The module
signs match results that the server itself observed; it never decides eligibility and it
never trusts client-reported scores. See `docs/REWARD_SECURITY.md` and `docs/API.md`.
