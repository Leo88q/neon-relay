== NAME
neonrelay - Starts the Neon Relay client.

== SYNOPSIS
*neonrelay* [_OPTION_]... [-f _CONFIG_FILE_]...

== DESCRIPTION
Neon Relay is a cooperative 2D platform/race game with a built-in reward rail for
Solana Mobile (Seeker) players. It is a standalone derivative of the upstream DDNet
project, which is itself an actively maintained version of *DDRace*, a *Teeworlds*
modification. See the repository files `UPSTREAM_BASE.md` and `license.txt` for the
exact upstream commit and for attribution.

Rewards are always decided by the game server and the reward service, never by the
client; the wallet connection is optional and the game is fully playable without it.

== EXAMPLES
*neonrelay* -f myfile.cfg

*neonrelay* -f myfile.cfg -f myfile2.cfg

*neonrelay* \'cl_showhud 0' \'player_name "nameless tee"'

== Options

=== Configuration file
*-f* _CONFIGURATION_FILE_::
Load _CONFIGURATION_FILE_ instead of the default _settings_neonrelay.cfg_

=== Other options
Every option is documented in-game (Settings) and in `src/engine/shared/config_variables.h`.
The upstream reference list of settings and commands is available from the DDNet project.
